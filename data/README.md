# Data

Place the Book-Crossing CSV files in `data/raw/`:

- `BX_Books.csv`
- `BX-Users.csv`
- `BX-Book-Ratings.csv`

The notebook expects semicolon-delimited files encoded as ISO-8859-1. The source dataset is commonly distributed as the Book-Crossing dataset. Preserve its original attribution and follow the dataset's applicable terms when using or sharing these files.

Do not put generated model artifacts, Spark checkpoints, or derived outputs in this directory.
